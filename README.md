# בנק מחשבות – אפליקציית Android

אפליקציה לשמירת מחשבות עם תזכורות בהתראה. כל המידע נשמר מקומית על הטלפון (SQLite), בלי חשבון ובלי ענן.

## מה יש בה
- רשימת מחשבות, החדשה ביותר למעלה, עם חיפוש.
- הוספה ועריכה של מחשבה. יציאה עם "חזור" שומרת אוטומטית.
- תזכורת לכל מחשבה: "בעוד שעה", "הערב 20:00", "מחר 09:00", או תאריך ושעה לבחירה.
- התראה בזמן שנקבע. לחיצה עליה פותחת את המחשבה.
- התזכורות נשמרות גם אחרי הפעלה מחדש של הטלפון.
- שיתוף טקסט מכל אפליקציה (Share → בנק מחשבות) שומר אותו כמחשבה חדשה.
- תמיכה במצב כהה.

## התקנה
1. חלץ את הזיפ.
2. ב-Android Studio: File → Open → בחר את התיקייה `ThoughtBank`.
3. חכה ל-Gradle Sync. בפעם הראשונה הוא מוריד את Gradle 8.9, ואם חסר, גם את SDK 35 (Studio יציע להתקין).
4. בטלפון: הפעל Developer options ו-USB debugging (או Wireless debugging), וחבר אותו.
5. בחר את הטלפון בסרגל העליון ולחץ Run ▶.
6. בפתיחה הראשונה אשר הרשאת התראות.

לחלופין: Build → Build App Bundle(s) / APK(s) → Build APK(s), העבר את ה-APK לטלפון והתקן ממנו.

## אם משהו לא עובד
- **Studio מציע לשדרג את Android Gradle Plugin** – אפשר לאשר.
- **ה-Sync נכשל בגלל Gradle wrapper** – צור פרויקט חדש ריק (Empty Views Activity, Java) והעתק אליו את תיקיית `app/src/main` ואת `app/build.gradle` מכאן.
- **התזכורות מגיעות באיחור או לא מגיעות** – בחלק מהטלפונים (Xiaomi, Samsung, OnePlus) חיסכון הסוללה עוצר אפליקציות. בהגדרות האפליקציה → סוללה → בחר "ללא הגבלה".

## מבנה הקוד
| קובץ | תפקיד |
|---|---|
| `MainActivity` | מסך ראשי: רשימה, חיפוש, כפתור + |
| `EditActivity` | יצירה ועריכה של מחשבה ותזכורת |
| `ThoughtDb` | שמירה וטעינה מ-SQLite |
| `ReminderScheduler` | קביעה וביטול של AlarmManager |
| `ReminderReceiver` | מציג את ההתראה כשהזמן מגיע |
| `BootReceiver` | מחזיר את התזכורות אחרי ריסטארט או עדכון |
